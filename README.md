# Анализ и прогнозирование временных рядов с использованием SSA
 
Анализ и прогнозирование временных рядов методом SSA (Singular Spectrum Analysis) - сингулярный спектральный анализ.
 
## Про что проект
 
Это мой проект где я разбирался с методом SSA и пробовал применять его к разным данным - финансовые ряды, нефть, ковид и т.д. Основная идея - разложить временной ряд на компоненты (тренд, сезонность, шум) и на основе этого делать прогноз.
 
Ядро проекта - класс `SSAv3` в файле `SSA2.py`, остальное это ноутбуки с экспериментами на разных данных.

## Как работает SSA2.py
 
Вкратце алгоритм такой:
 
1. **Embedding** - из одномерного ряда длины N строится траекторная матрица (матрица Ханкеля) размера L×K, где L - размерность вложения
2. **SVD** - сингулярное разложение траекторной матрицы, получаем собственные тройки (λ, U, V)
3. **Группировка** - выбираем какие компоненты относятся к сигналу, а какие к шуму (смотрим на вклады λ)
4. **Реконструкция** - диагональное усреднение (anti-diagonal averaging) для восстановления ряда из выбранных компонент
5. **Прогноз** - рекуррентный прогноз на основе коэффициента вертикальности R
 
Пример использования:
```python
from SSA2 import SSAv3
 
ssa = SSAv3(data['price'])
ssa.embed(embedding_dimension=40, frequency=7)
ssa.SVD()
 
# посмотреть вклады компонент
ssa.view_s_contributions()
 
# реконструкция из первых 5 компонент
ssa.view_reconstruction(*[ssa.Xs[i] for i in range(5)], names=list(range(5)))
 
# прогноз на 30 шагов вперед
forecast = ssa.forecast_recurrent(steps_ahead=30, singular_values=list(range(5)), plot=True, return_df=True)
```

## Заметки
 
- Параметр `embedding_dimension` сильно влияет на результат, подбирал руками под каждый датасет
- `frequency` в embed() нужен если есть выраженная сезонность - окно подгоняется под кратность периода
- В ноутбуках `streams1` и `streams2` - это мои группировки компонент (сигнал vs шум), тоже подбирал вручную по графикам вкладов
- Код местами не очень чистый, ноутбуки писались в процессе экспериментов
